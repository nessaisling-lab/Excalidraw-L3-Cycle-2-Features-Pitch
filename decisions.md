# decisions.md — Persistent Save (C1 First-Save Moment)

Running log of every decision made on this build: what was decided, who made the call, and why. This is the team's working reference — kept in the repo, not the PRD, so it's easy to grep and diff alongside the code it governs.

The PRD (`persistent-save-master-prd.md`) states final requirements only. This file is where the reasoning and history live. When the two ever seem to disagree, the PRD wins for what to build; this file explains why it says what it says.

**This version (2026-09-23, handoff):** history unchanged; 9/22 and 9/23 rows appended in their own sections; Still open rebuilt; closed questions moved to Archived with how each closed.

**Maintainers:** whole team. Append, don't rewrite history — if a decision changes, add a new row noting the supersession rather than editing the old one.
